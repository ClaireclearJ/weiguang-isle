# 微光岛 · 引路人的委托

一个受《光·遇》启发的 2.5D 浮空岛探索小游戏。单文件、零依赖，打开 `index.html` 即可游玩。

## 玩法

- 在四座地形完全不同的浮空岛之间探索
- 找到引路人，点亮石碑，完成它们布置的小委托
- 回到引路人身边领取星火与表情
- 完成委托后，可以和引路人一起玩、摘果子、看风景

## 四座岛

| 岛 | 地形 | 委托 | 伙伴 |
|---|---|---|---|
| 🌿 草原岛 | 圆形岛，水潭 / 草甸 / 石径 | 点灯 · 采花 · 安慰小狐 | 暖风 / 星光 / 守望 |
| 🌙 星夜岛 | 环形岛，中央星渊 | 敲星铃 · 拾星光 · 陪伴小鹿 | 守夜 / 拾光 / 织星 |
| 🏜️ 沙海岛 | 月牙岛，沙丘 / 仙人掌 | 摆引路石 · 找水洼 · 陪沙狐 | 沙歌 / 旅人 / 守井 |
| ❄️ 雪原岛 | 三瓣岛，冰湖 / 冰柱 | 点暖炉 · 采冰晶 · 暖雪狐 | 霜语 / 极光 / 守炉 |

## 操作

- `WASD` / 方向键：移动
- `空格`：飞 / 滑翔
- `E`：互动
- `1 / 2 / 3`：表情
- `🧭`：换岛
- `🔤`：朗读开关（可选，自动挑自然中文音色）

## 技术

- 单文件 `index.html`（约 130KB），Canvas 2D 程序化绘制，无外部依赖
- 2.5D 斜俯视、近大远小、脚下影子、远近遮挡排序
- 进度保存在浏览器 `localStorage`
- 程序化合成分离音 / 环境声，默认静音

## 本地运行

双击 `index.html` 即可，或：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000
